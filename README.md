# Ghost story

(name tbi)

A small-scoped game to learn Godot.

## Story summary

_The ghost_, terrified of strangers, tries to scare off intruders without being seen.

## Gameplay

The ghost can hide in objects or stay out of the flashlights. Objects break when exited, scaring the strangers. Being seen scares both characters. 
Once an enemy has been sufficiently scared, they're terrified and easy to chase away.

There is no actual penalty for being spotted, it's just something the ghost dislikes.

## Build

The game runs in Godot 4.3, with art made in Pixelorama. Have fun!
